## 便宜 Linux VPS 和共享主机到底差在哪

这个问题在 Reddit 上几乎每周都有人问。简单说一下区别，因为很多人在两者之间犹豫不决。

**共享主机**：便宜是真便宜，1 美元出头就能起步。但你拿到的是一个受限的账户，没有 root 权限，不能装软件，不能改系统配置，只能跑 PHP 网站。资源是和别人共享的，隔壁站点流量一爆，你的网站跟着卡。适合纯小白，只想放个 WordPress 不想折腾的那种。

**VPS**：贵一点，但你有完整的 root 权限，整台机器都是你的，想装什么装什么，想怎么折腾怎么折腾。资源是隔离的，不会受邻居影响。代价是你得自己懂点 Linux，或者愿意学。Evoxt 官网 FAQ 里说得很直白：VPS 给你的是专用环境、完整 root 权限、想干嘛干嘛；共享主机一切是共享的，你只是个权限受限的用户，干不了太多事。

> 一句话总结：纯小白放博客，共享主机够用；想折腾、想学东西、想跑点别的东西，那就 VPS。便宜 Linux VPS 的意义，就是让"折腾"这件事的门槛从几十美元降到几美元。

## 便宜 Linux VPS 的常见坑：买之前先看看

最后说几个新手容易踩的坑，这部分跟厂商关系不大，是 cheap VPS Linux 这个领域通用的。

**流量不是无限的**：Evoxt Standard 网络最低 500GB/月，Premium 网络最低 250GB/月。跑 VPN、视频代理这类吃流量的应用，要算清楚流量。超了之后 Standard 是 $3/TB、Premium 是 $12/TB、Premium Plus 是 $24/TB，超流量费不便宜。

**便宜 VPS 不适合跑生产业务**：如果你是要给客户上线一个网站、跑一个有真实用户的服务，便宜 VPS 的稳定性可能撑不住。Evoxt 这种适合个人项目、学习、自托管，不适合跑生产。生产业务老老实实选 AWS、GCP、Azure 这种大厂，或者 Hetzner、DigitalOcean 这种中端厂商。

**备份重要，但别只靠厂商的备份**：Evoxt 给的每周异地备份是好事，但备份频率是一周一次。如果你的数据变化频繁，最好自己再搞一套日备份方案，用 rclone 同步到 Backblaze B2、Cloudflare R2 这种便宜的对象存储。

**注意 IP 是否被墙**：便宜 VPS 的 IP 段经常被各种服务封禁。买了机器先测一下 IP 干净度，看看能不能访问 Netflix、ChatGPT、Google 这些服务。Evoxt 可以付费换 IP（$3/月一个额外 IP），需要的话可以加。

**别用 root 跑服务**：连上 VPS 第一件事就是建个普通用户，给 sudo 权限，禁掉 root 直接 SSH 登录。这是 Linux 服务器的基本操作，但很多新手不知道，结果机器没几天就被爆破挂了。
